# Software documentation / Documentación de software

Document the software architecture and the responsibilities of each module. Keep implementation-specific instructions close to the corresponding source directory.

Documentar la arquitectura del software y las responsabilidades de cada módulo. Mantener las instrucciones específicas de implementación cerca del directorio de código correspondiente.

Suggested topics / Temas sugeridos:
- Installation and environment / Instalación y entorno.
- Software architecture / Arquitectura del software.
- Coordinate conventions and units / Convenciones de coordenadas y unidades.
- Kinematics / Cinemática.
- Motion command format and interpreter / Formato de comandos e intérprete.
- Motion execution and drive interface / Ejecución de movimiento e interfaz con controladores.
- GUI operation / Operación de la interfaz.
- Logging and fault handling / Registro y gestión de fallas.
- Tests / Pruebas.
