# Mechanical documentation / Documentación mecánica

Store design rationale and released documentation here. Store native CAD and manufacturing files in the top-level `mechanical/` directory.

Guardar aquí la justificación del diseño y la documentación liberada. Los archivos CAD nativos y de fabricación se almacenan en `mechanical/`.

Suggested documents / Documentos sugeridos:
- Mechanical architecture / Arquitectura mecánica.
- Assembly procedure / Procedimiento de ensamble.
- Bill of materials (BOM) / Lista de materiales.
- Drawing index / Índice de planos.
- Material and manufacturing specifications / Especificaciones de materiales y fabricación.
- Inspection and maintenance / Inspección y mantenimiento.
