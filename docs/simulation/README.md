# Simulation documentation / Documentación de simulación

Record the simulator and version, model source, import settings, coordinate conventions, joint limits, dynamic parameters, scene configuration, test cases, and known limitations.

Registrar simulador y versión, origen del modelo, parámetros de importación, convenciones de coordenadas, límites articulares, parámetros dinámicos, configuración de escena, casos de prueba y limitaciones conocidas.

Clearly distinguish kinematic visualization from dynamic or physical simulation. A simulation result is not experimental validation of the physical robot.

Distinguir claramente la visualización cinemática de la simulación dinámica o física. Un resultado de simulación no constituye validación experimental del robot físico.
