# Electronics documentation / Documentación electrónica

Document the electrical architecture, power distribution, wiring, connectors, controller configuration, communication protocols, grounding, and protection.

Documentar arquitectura eléctrica, distribución de alimentación, cableado, conectores, configuración de controladores, protocolos de comunicación, puesta a tierra y protecciones.

For each component, record manufacturer, exact model, datasheet, operating limits, configuration, and the subsystem where it is used.

Para cada componente, registrar fabricante, modelo exacto, hoja de datos, límites de operación, configuración y subsistema donde se utiliza.
