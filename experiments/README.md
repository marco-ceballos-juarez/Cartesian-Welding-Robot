# Experimental records

Separate test procedures, raw measurements, processed results, and reports. Never overwrite raw data; store processed data in a separate location.

Each experiment should include:
- Unique test ID and date.
- Objective and requirement being evaluated.
- Hardware and software revisions.
- Test setup and instruments.
- Procedure and operating conditions.
- Raw data files.
- Processing scripts and metrics.
- Results, observations, and limitations.
- Evidence (photos, plots, logs) where appropriate.

Do not place personal or sensitive information in the repository.
