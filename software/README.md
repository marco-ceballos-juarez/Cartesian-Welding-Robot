# Software

This directory contains software developed for the robot. Each module should have a README describing purpose, supported environment, dependencies, configuration, how to run it, and how to test it.

Suggested modules:
- `kinematics/`
- `trajectory_planning/`
- `motion_control/`
- `gcode_interpreter/`
- `communication/`
- `gui/`
- `tests/`

Do not assume these modules are already implemented; add source files as they become available.
