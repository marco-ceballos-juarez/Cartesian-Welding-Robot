# Thesis material / Material de tesis

Use this directory for thesis source files and supplementary material that is appropriate to keep under version control.

Suggested:
- `source/`: LaTeX or other editable source.
- `figures/`: thesis-specific figures.
- `tables/`: generated tables.
- `supplementary/`: additional material.

Avoid committing build artifacts (PDF intermediates, auxiliary files, caches) unless a specific released document is intentionally versioned. Respect institutional and publication requirements before making thesis material public.
