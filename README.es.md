# Robot cartesiano para soldadura

Este archivo ofrece la descripción del proyecto en español. La página principal del repositorio está en [`README.md`](README.md).

## Propósito

Documentar y organizar el desarrollo de una plataforma robótica cartesiana de arquitectura abierta adaptada para aplicaciones de soldadura. El repositorio reúne diseño mecánico, electrónica, software, simulación, procedimientos experimentales y documentación técnica.

El proyecto se encuentra en desarrollo e integración. La presencia de una carpeta o documento no implica que esa función esté terminada o validada.

## Organización

- `docs/`: documentación técnica y guías.
- `mechanical/`: CAD, planos, ensambles y lista de materiales.
- `electronics/`: diagramas eléctricos, cableado y componentes.
- `software/`: cinemática, planificación de movimiento, intérprete de comandos, control, comunicación e interfaz.
- `simulation/`: modelo URDF y proyectos de simulación.
- `experiments/`: protocolos, datos sin procesar y resultados.
- `thesis/`: fuente de tesis y material complementario.

## Criterios de documentación

Cada subsistema debe indicar su estado, revisión, requisitos, procedimiento de instalación o ensamblaje, configuración y método de verificación. Los resultados experimentales deben distinguirse de las simulaciones y de los resultados esperados.
